# AI Resume Analyzer

An AI-powered resume analysis application that helps users evaluate how well their resume matches a specific job role and job description. The system analyzes resume content, identifies relevant skills, highlights missing skills, calculates a match score, and provides suggestions for improvement.

---

## 📌 Project Overview

Finding out whether a resume is suitable for a particular job can be difficult and time-consuming.

The **AI Resume Analyzer** provides a simple way to compare a candidate's resume with a target job description.

Users can upload their resume as a PDF, enter the desired job role and job description, and receive an analysis containing:

- Resume skills
- Required job skills
- Matching skills
- Missing skills
- Resume match score
- Improvement suggestions

The application provides these results through an interactive **Streamlit web interface**.

---

## 🎯 Objectives

The main objectives of the project are:

- To analyze resume content automatically.
- To identify skills present in a candidate's resume.
- To identify skills required for a target job.
- To determine the skills that match between the resume and job requirements.
- To identify missing or insufficient skills.
- To calculate a resume-job match score.
- To provide suggestions that can help improve the resume.
- To provide a simple and user-friendly interface for resume analysis.
